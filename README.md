# solo7.media

Brand kits and websites for Valesor Development, System 9 Studios, Solo7 Productions, solo7.media, and
bashburn.com. Each site deploys to Cloudflare Workers static assets.

- `brands/<slug>/`: one brand kit per property (docs, tokens, art, components)
- `sites/<domain>/`: one Astro site per domain
- `packages/`: shared non-visual code
- `docs/`: product plan, ADRs, specs, sprint records, runbooks

`make help` lists the build targets. `CLAUDE.md` describes how the agent roles work here.
